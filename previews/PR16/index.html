Autoscalers.jl

Automated finite-size scaling analysis (data collapse) in Julia.

Public interface

Autoscalers.@ansatz — Macro
@ansatz (params...) -> lhs ~ rhs [size=:L] [x=:col] [group=:col]

Define a scaling Ansatz from a formula: the data collapse is sought for lhs (the scaled y) as a function of rhs (the scaled x).

Syntax

  • (params...) -> declares the parameters, in the order the Autoscaler expects their values. A single parameter can be written without parentheses.
  • :col is a column of the data. Names that are not identifiers can be written as :var"col name".
  • :col ± :col_err attaches the errors in column col_err to col. The left-hand side must contain at least one such column; their errors propagate into the scaled y.
  • $expr inserts the value of expr once, when the ansatz is created.
  • Any other name (a function, a constant like π, a variable) is looked up in the calling scope.

Options

  • size: column with the system size (default :L).
  • x: column with the unscaled x, which the rows are sorted by and eval_window refers to. Only needed when the right-hand side uses more than one column besides size and group.
  • group: further columns (one, or a tuple) that identify a curve together with size; see Ansatz.

Examples

julia> a = @ansatz (a, b, x_c) -> :L^b * (:y ± :y_err) ~ :L^a * (:x - x_c);

julia> a.param_names, a.x, a.errors
((:a, :b, :x_c), :x, (y = :y_err,))

julia> a.f((; L=4, x=0.5, y=2.0), (; a=1.0, b=0.5, x_c=0.3))  # scaled (x, y)
(0.8, 4.0)

An analytic background, a fixed exponent, and other column names:

julia> ν = 0.75;

julia> a = @ansatz (A, B, t_c) -> :N^0.1 * ((:E ± :dE) - A - B * (:t - t_c)) ~
           :N^(1 / $ν) * (:t - t_c) size=:N;

julia> a.size, a.x
(:N, :t)

One curve per size and value of u, all sharing one master curve:

julia> a = @ansatz (α, β, t_c) ->
           :L^0.1 * ((:E ± :dE) - :u - α * :u^2 - β * (:t - t_c) * :u^2) ~
           :L^1.5 * (:t - t_c) group=:u;

julia> a.group
(:u,)

Autoscalers.Ansatz — Type
Ansatz(f, params; x, errors, columns=(), size=:L, group=())

Scaling ansatz given as a function f(row, p) that returns the scaled (x, y) of one data point. @ansatz builds the same from a formula.

row is a NamedTuple of the point's values in the columns size, group, x, the keys of errors and columns. p is a NamedTuple of the parameters.

The columns listed in errors are passed as ForwardDiff dual numbers that carry their errors, so the error of the scaled y follows from first-order error propagation (assuming independent errors). Therefore:

  • f must accept any Real, not only Float64;
  • the scaled y must depend on at least one column with errors;
  • the scaled x must not depend on any column with errors.

Arguments

  • params: parameter names, in the order the Autoscaler expects their values.
  • x: column with the unscaled x. Rows are sorted by it, and eval_window refers to it.
  • errors: NamedTuple mapping columns to their error columns, e.g. (; E=:dE).
  • columns: further columns used by f.
  • size: column with the system size. Its values are passed as integers.
  • group: further columns (a name or a tuple of names) that identify a curve together with size, e.g. group=:u when there is one curve per size and value of u. Each point is then compared with the master curve of all other curves. By default, each size is one curve. Group columns must be numeric, cannot be named like an output of to_table, and the data still needs at least two sizes.

Examples

julia> a = Ansatz((:a, :b, :t_c); x=:t, errors=(; E=:dE)) do row, p
           return row.L^p.a * (row.t - p.t_c), row.L^p.b * row.E
       end;

julia> a.param_names
(:a, :b, :t_c)

julia> a.f((; L=4, t=0.5, E=2.0), (; a=1.0, b=0.5, t_c=0.3))  # scaled (x, y)
(0.8, 4.0)

Autoscalers.Autoscaler — Type
Autoscaler(
    table, ansatz::Ansatz=DEFAULT_ANSATZ;
    eval_window=nothing,
    penalty=100.0,
    classic_cost_function=false,
    use_all_sizes=false,
    fix=(;),
)

Prepare the data in table (any Tables.jl table) for a data collapse with ansatz. The default ansatz is @ansatz (a, b, x_c) -> :L^b * (:y ± :y_err) ~ :L^a * (:x - x_c).

Calling the Autoscaler with values of the free parameters returns the cost of the collapse, which fit_collapse minimises. The parameters are those of ansatz.param_names, in that order, without the fixed ones.

Cost functions

Each data point is compared with the master curve built from all other curves (a curve is one size, or one combination of size and ansatz.group values). One of the two cost functions must be chosen:

  • Fixed window (eval_window = (lo, hi)): only points with $\mathrm{lo} ≤ x ≤ \mathrm{hi}$ in the unscaled $x$ are scored, so the scored set does not change with the parameters. Points outside it still serve for interpolation. Where another curve does not reach a point's scaled $x$, it is extrapolated linearly and penalty $× d^2$ is added, with $d$ the distance outside in units of that curve's scaled range.
  • Classic (classic_cost_function=true): the cost of Houdayer & Hartmann (2004), with a local linear fit through the neighbouring points of the other curves. It scores every point where the curves overlap in the scaled $x$, so for the smallest sizes it reaches furthest from the transition, where corrections to scaling are largest.

The scaling form holds as $t → 0$ in the unscaled $t$, for any scaled $x$. A window in the unscaled $x$ bounds the corrections that grow with $|t|$ equally for all sizes, so the fixed window is recommended.

Keywords

  • use_all_sizes: also include a point's own curve in its master curve (fixed-window cost only).
  • fix: parameters held at fixed values, e.g. fix=(; a=1/ν). They are left out of the arguments of the cost.

Data requirements

  • Only the columns used by ansatz are read. Rows with missing or non-finite values in them, or with a non-positive error, are skipped with a warning.
  • Sizes must be positive integers, and there must be at least two of them.
  • Each curve needs at least two rows, with distinct x.

An Autoscaler reuses internal buffers, so one instance must not be evaluated from several threads at once; see Autoscaler(::Autoscaler) for independent copies.

Examples

julia> data = [(; L, x, y=L^-0.25 * tanh(L * (x - 0.3)), y_err=1e-3)
               for L in (8, 16, 32) for x in 0.2:0.005:0.4];

julia> s = Autoscaler(data; eval_window=(0.28, 0.32));

julia> round(s(1.0, 0.25, 0.3); digits=3)  # a, b, x_c: a good collapse
0.005

julia> round(s(1.2, 0.25, 0.3); digits=1)  # a bad one
270.2

julia> s_b = Autoscaler(data; eval_window=(0.28, 0.32), fix=(; b=0.25));

julia> s_b(1.0, 0.3) == s(1.0, 0.25, 0.3)
true

References

  • J. Houdayer and A. K. Hartmann, Low-temperature behavior of two-dimensional Gaussian Ising spin glasses, Phys. Rev. B 70, 014418 (2004), doi:10.1103/PhysRevB.70.014418.

Autoscalers.cost_breakdown — Function
cost_breakdown(a::Autoscaler, args...)

The fixed-window cost at the free parameters args, split into its parts: a NamedTuple (; cost, chi2, penalty) with cost = chi2 + penalty. Requires eval_window.

A non-negligible penalty means the collapse relies on extrapolating curves beyond their data; shrink eval_window until it vanishes.

Examples

julia> data = [(; L, x, y=L^-0.25 * tanh(L * (x - 0.3)), y_err=1e-3)
               for L in (8, 16, 32) for x in 0.2:0.005:0.4];

julia> s = Autoscaler(data; eval_window=(0.28, 0.32));

julia> map(c -> round(c; digits=3), cost_breakdown(s, 1.0, 0.25, 0.3))
(cost = 0.005, chi2 = 0.005, penalty = 0.0)

Autoscalers.to_table — Function
to_table(a::Autoscaler, args...)

The data scaled with the free parameters args, for plotting the collapse. Returns a NamedTuple of columns, one row per data point:

  • L: system size;
  • the group columns of the ansatz, if any;
  • x, y, y_err: scaled values;
  • master_curve: the master curve the point is compared to;
  • in_window: whether the point is scored by the fixed-window cost.

The column names are always these, whatever the columns are called in the data.

Examples

julia> data = [(; L, x, y=L^-0.25 * tanh(L * (x - 0.3)), y_err=1e-3)
               for L in (8, 16, 32) for x in 0.2:0.005:0.4];

julia> t = to_table(Autoscaler(data; eval_window=(0.28, 0.32)), 1.0, 0.25, 0.3);

julia> keys(t)
(:L, :x, :y, :y_err, :master_curve, :in_window)

julia> count(t.in_window)
27

Autoscalers.fit_collapse — Function
fit_collapse(
    a::Autoscaler, x0;
    method=NelderMead(...), options=Optim.Options(...), restarts=1,
)

Minimise the cost of a over its free parameters with Optim.jl, starting from x0.

Returns a NamedTuple with

  • params: the fitted free parameters;
  • cost: the cost at params;
  • converged: whether the optimiser converged;
  • result: the Optim result of the last run, for details such as the number of iterations (nothing if all parameters are fixed).

By default this uses the Nelder–Mead simplex method with a small initial simplex around x0. It is restarted restarts times from the previous minimum, because a single run can stall in an elongated simplex. Any derivative-free Optim method and options can be passed instead.

Examples

julia> data = [(; L, x, y=L^-0.25 * tanh(L * (x - 0.3)), y_err=1e-3)
               for L in (8, 16, 32) for x in 0.2:0.005:0.4];

julia> fit = fit_collapse(Autoscaler(data; eval_window=(0.28, 0.32)), [1.1, 0.2, 0.31]);

julia> fit.converged
true

julia> round.(fit.params; digits=3)  # a, b, x_c
3-element Vector{Float64}:
 0.999
 0.249
 0.3

Autoscalers.bootstrap — Function
bootstrap(
    a::Autoscaler, estimate;
    n=1000, rng=Random.default_rng(), parallel=true, progress=isinteractive(),
    method=NelderMead(...), options=Optim.Options(...),
)

Parametric bootstrap (Efron & Tibshirani, 1993; Davison & Hinkley, 1997) of the free parameters around their fitted values estimate. Returns a BootstrapResult, for use with confint, stderror and pvalue.

The fitted collapse is taken as the true model:

  1. At estimate, the master curve at each point is the error-weighted mean of all curves covering it. The ansatz is inverted to map it back to the data, for the first column with errors.
  2. Each of the n replicates adds Gaussian noise of the measured errors to that model (and to the other columns with errors).
  3. Each replicate is refitted with fit_collapse, using method and options, starting from estimate.

The spread of the refitted parameters estimates the statistical error only. Systematic errors, for example from the choice of eval_window or corrections to scaling, are not included.

Keywords

  • n: number of replicates.
  • rng: random number generator. The results are reproducible for a given rng, whatever the number of threads.
  • parallel: run the replicates on all Julia threads (start Julia with --threads).
  • progress: show a progress bar (by default in interactive sessions).
  • method, options: passed to fit_collapse.

Examples

julia> using Random

julia> data = [(; L, x, y=L^-0.25 * tanh(L * (x - 0.3)), y_err=1e-3)
               for L in (8, 16, 32) for x in 0.2:0.005:0.4];

julia> s = Autoscaler(data; eval_window=(0.28, 0.32));

julia> fit = fit_collapse(s, [1.1, 0.2, 0.31]);

julia> b = bootstrap(s, fit.params; n=200, rng=Xoshiro(1));

julia> b
BootstrapResult(a, b, x_c; 200/200 replicates converged)

julia> round.(confint(b).a; digits=2)
(0.92, 1.05)

References

  • B. Efron and R. J. Tibshirani, An Introduction to the Bootstrap, Chapman & Hall (1993), doi:10.1201/9780429246593 (CRC reprint).
  • A. C. Davison and D. V. Hinkley, Bootstrap Methods and their Application, Cambridge University Press (1997), doi:10.1017/CBO9780511802843.

BootstrapResult

Result of bootstrap. Use confint, stderror and pvalue on it; these use only the replicates whose fit converged.

Fields

  • estimate: the free parameters the bootstrap was run at.
  • samples: the refitted free parameters, one row per replicate and one column per parameter.
  • converged: whether each replicate's fit converged.

StatsAPI.confint — Method
confint(b::BootstrapResult; level=0.95)

Bias-corrected percentile (BC) confidence intervals (Efron, 1987) of every free parameter, as a NamedTuple of (lower, upper).

The intervals follow the shape of the bootstrap distribution, so they can be asymmetric around the estimate. They need no extra fits, and on synthetic collapses they are close to their nominal coverage (see test/scripts/bootstrap_coverage.jl).

Method

With level $= 1 - α$, the bounds are the quantiles of the samples at the levels $Φ(2z_0 ± z_{α/2})$, where $Φ$ is the standard normal distribution function and $z_0 = Φ^{-1}(P(θ^* < \hat{θ}))$ measures how far the bootstrap distribution is off-centre from the estimate.

  • For a centred distribution ($z_0 = 0$), this is the plain percentile interval.
  • A large $|z_0|$ moves the levels towards 0 or 1, where quantiles need many replicates ($n \gtrsim 1000$).

Other intervals can be computed from b.samples, using the rows marked in b.converged.

Examples

julia> using Random

julia> data = [(; L, x, y=L^-0.25 * tanh(L * (x - 0.3)), y_err=1e-3)
               for L in (8, 16, 32) for x in 0.2:0.005:0.4];

julia> s = Autoscaler(data; eval_window=(0.28, 0.32));

julia> fit = fit_collapse(s, [1.1, 0.2, 0.31]);

julia> b = bootstrap(s, fit.params; n=200, rng=Xoshiro(1));

julia> round.(confint(b).a; digits=2)
(0.92, 1.05)

julia> round.(confint(b; level=0.68).a; digits=2)
(0.95, 1.02)

References

  • B. Efron, Better bootstrap confidence intervals, J. Am. Stat. Assoc. 82, 171 (1987), doi:10.1080/01621459.1987.10478410.

StatsAPI.pvalue — Method
pvalue(b::BootstrapResult, name => value...; method=:bc, kwargs...)

Two-sided p-value of the hypothesis that the parameters name equal value.

Methods

method=:bc (default, no extra fits) tests one parameter. It is the test dual to the BC interval of confint (Efron, 1987): $p < α$ exactly when value lies outside the interval of level $= 1 - α$, up to the resolution of the replicates.

  • The fractions $P$ of samples below and above value, with the $+1$ correction (Davison & Hinkley, 1997, see bootstrap), are mapped through $Φ(Φ^{-1}(P) ∓ 2z_0)$, and $p$ is twice the smaller one.
  • On the side towards which the BC interval is stretched, the smallest attainable p-value is $2Φ(Φ^{-1}(1/(n + 1)) + 2|z_0|)$: about 0.005 for $n = 1000$ and $|z_0| = 0.15$, but 0.06 for $|z_0| = 0.6$. To reject strongly off-centre cases, use more replicates or method=:null.

method=:null follows the first guideline of Hall & Wilson (1991): it resamples under the hypothesis.

  • The parameters are refitted with name fixed at value, and the replicates are drawn from that constrained collapse.
  • Each replicate is fitted with and without the constraint. $p$ is the fraction of replicates whose cost increase from the constraint is at least the observed one (with the $+1$ correction).
  • It can test several parameters at once and needs $2n$ fits.
  • The keywords n (default: the number of replicates of b), rng, parallel and progress are as for bootstrap.

Examples

julia> using Random

julia> data = [(; L, x, y=L^-0.25 * tanh(L * (x - 0.3)), y_err=1e-3)
               for L in (8, 16, 32) for x in 0.2:0.005:0.4];

julia> s = Autoscaler(data; eval_window=(0.28, 0.32));

julia> fit = fit_collapse(s, [1.1, 0.2, 0.31]);

julia> b = bootstrap(s, fit.params; n=200, rng=Xoshiro(1));

julia> round(pvalue(b, :a => 1.0); digits=2)  # the true value
0.86

julia> round(pvalue(b, :a => 1.1); digits=3)
0.004

References

  • B. Efron, Better bootstrap confidence intervals, J. Am. Stat. Assoc. 82, 171 (1987), doi:10.1080/01621459.1987.10478410.
  • P. Hall and S. R. Wilson, Two guidelines for bootstrap hypothesis testing, Biometrics 47, 757 (1991), doi:10.2307/2532163.
