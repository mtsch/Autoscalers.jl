Autoscalers.jl

Automated finite-size scaling analysis (data collapse) in Julia.

Public interface

Autoscalers.@ansatz — Macro
@ansatz (params...) -> lhs ~ rhs [size=:L] [x=:col]

Define a scaling Ansatz: the collapse is sought for lhs (the scaled y) as a function of rhs (the scaled x).

  • (params...) declares the parameters, in the order the Autoscaler expects their values. A single parameter can be written without parentheses.
  • :col refers to a column of the data. Names that are not valid identifiers can be written as :var"col name".
  • :col ± :col_err attaches the errors in column col_err to col. The left-hand side must contain at least one such column; their errors propagate into the scaled y.
  • $expr inserts the value of expr when the ansatz is created.
  • Any other name, such as a function, a constant like π or a variable, is resolved in the calling scope.
  • size names the column with the system size (default :L).
  • x names the column with the unscaled x, which the data are sorted by and eval_window refers to. By default it is the only column on the right-hand side besides size.

Examples

@ansatz (a, b, x_c) -> :L^b * (:y ± :y_err) ~ :L^a * (:x - x_c)

# analytic background, a fixed exponent, and different column names
ν = 0.75
@ansatz (A, B, t_c) -> :N^0.1 * ((:E ± :dE) - A - B * (:t - t_c)) ~
    :N^(1/$ν) * (:t - t_c) size=:N

Autoscalers.Ansatz — Type
Ansatz(f, params; x, errors, columns=(), size=:L)

Scaling ansatz given as a function. f(row, p) returns the scaled (x, y) of one data point, where row is a NamedTuple with the columns size, x, the keys of errors and columns, and p is a NamedTuple of the parameters named in params.

Columns listed in errors are passed as Measurements carrying the error from their error column, so the uncertainty of the scaled y follows from error propagation. The scaled y must depend on at least one of them and the scaled x on none.

  • params: parameter names, in the order the Autoscaler expects their values.
  • x: column with the unscaled x. Rows are sorted by it, and eval_window refers to it.
  • errors: NamedTuple mapping columns to their error columns, e.g. (; E=:dE).
  • columns: further columns used by f.
  • size: column with the system size. Its values are passed as integers.

@ansatz builds the same from a formula.

Example

Ansatz((:a, :b, :t_c); x=:t, errors=(; E=:dE)) do row, p
    return row.L^p.a * (row.t - p.t_c), row.L^p.b * row.E
end

Autoscalers.Autoscaler — Type
Autoscaler(
    table, ansatz::Ansatz=DEFAULT_ANSATZ;
    classic_cost_function=false,
    use_all_sizes=false,
    window_width=1,
    eval_window=nothing,
    penalty=100.0,
    fix=(;),
)

Prepare table for finite-size scaling with ansatz. Calling the result with the free parameters (in the order of ansatz.param_names, skipping hardcoded ones) returns the cost.

  • classic_cost_function: use the cost function of Houdayer & Hartmann (2004) (per-point, local linear master curve) instead of the integral cost.
  • use_all_sizes: include a curve's own size when building the master curve it is compared to (default: leave it out).
  • window_width: fraction of the scaled overlap window used by the integral cost.
  • eval_window = (lo, hi): use the fixed-window cost. Only data points with lo ≤ x ≤ hi in the raw (unscaled) x are scored, independently of the parameters. Points outside it still serve as interpolation knots. Where another size does not cover a point's scaled x, its curve is extrapolated linearly and a smooth penalty penalty * d^2 is added (d = distance outside, in units of that size's scaled range).
  • fix: NamedTuple of parameters held at fixed values, e.g. fix=(; a=1/ν). They are left out of the arguments of the cost function.

Only the columns used by ansatz are read. Rows with missing or non-finite values in them, or with a non-positive error, are skipped with a warning. System sizes must be positive integers, each size needs at least two usable rows, and no two rows may share the same size and x.

The Autoscaler reuses internal buffers between calls, so a single instance must not be evaluated from several threads at once.

References

  • J. Houdayer and A. K. Hartmann, Low-temperature behavior of two-dimensional Gaussian Ising spin glasses, Phys. Rev. B 70, 014418 (2004), doi:10.1103/PhysRevB.70.014418.

Autoscalers.cost_breakdown — Function
cost_breakdown(a::Autoscaler, args...)

Return (; cost, chi2, penalty) at the free parameters args (same convention as calling the Autoscaler). Requires eval_window. A non-negligible penalty means the fit relies on extrapolated curves; shrink eval_window.

Autoscalers.to_table — Function
to_table(a::Autoscaler, args...)

Scale the data with the free parameters args and return a named tuple of columns L, x, y, y_err (scaled), master_curve (value of the master curve the point is compared to), and in_window (whether the point is scored by the fixed-window cost).
