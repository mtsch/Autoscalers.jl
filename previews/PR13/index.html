Autoscalers.jl

Automated finite-size scaling analysis (data collapse) in Julia.

Public interface

Autoscalers.@ansatz — Macro
@ansatz (params...) -> lhs ~ rhs [size=:L] [x=:col]

Define a scaling Ansatz: the collapse is sought for lhs (the scaled y) as a function of rhs (the scaled x).

  • (params...) declares the parameters, in the order the Autoscaler expects their values. A single parameter can be written without parentheses.
  • :col refers to a column of the data. Names that are not valid identifiers can be written as :var"col name".
  • :col ± :col_err attaches the errors in column col_err to col. The left-hand side must contain at least one such column; their errors propagate into the scaled y.
  • $expr inserts the value of expr when the ansatz is created.
  • Any other name, such as a function, a constant like π or a variable, is resolved in the calling scope.
  • size names the column with the system size (default :L).
  • x names the column with the unscaled x, which the data are sorted by and eval_window refers to. By default it is the only column on the right-hand side besides size.

Examples

@ansatz (a, b, x_c) -> :L^b * (:y ± :y_err) ~ :L^a * (:x - x_c)

# analytic background, a fixed exponent, and different column names
ν = 0.75
@ansatz (A, B, t_c) -> :N^0.1 * ((:E ± :dE) - A - B * (:t - t_c)) ~
    :N^(1/$ν) * (:t - t_c) size=:N

Autoscalers.Ansatz — Type
Ansatz(f, params; x, errors, columns=(), size=:L)

Scaling ansatz given as a function. f(row, p) returns the scaled (x, y) of one data point, where row is a NamedTuple with the columns size, x, the keys of errors and columns, and p is a NamedTuple of the parameters named in params.

Columns listed in errors are passed as ForwardDiff dual numbers that carry the error from their error column, so the uncertainty of the scaled y follows from first-order error propagation (independent errors). f must therefore accept any Real. The scaled y must depend on at least one of these columns and the scaled x on none.

  • params: parameter names, in the order the Autoscaler expects their values.
  • x: column with the unscaled x. Rows are sorted by it, and eval_window refers to it.
  • errors: NamedTuple mapping columns to their error columns, e.g. (; E=:dE).
  • columns: further columns used by f.
  • size: column with the system size. Its values are passed as integers.

@ansatz builds the same from a formula.

Example

Ansatz((:a, :b, :t_c); x=:t, errors=(; E=:dE)) do row, p
    return row.L^p.a * (row.t - p.t_c), row.L^p.b * row.E
end

Autoscalers.Autoscaler — Type
Autoscaler(
    table, ansatz::Ansatz=DEFAULT_ANSATZ;
    classic_cost_function=false,
    use_all_sizes=false,
    window_width=1,
    eval_window=nothing,
    penalty=100.0,
    fix=(;),
)

Prepare table for finite-size scaling with ansatz. Calling the result with the free parameters (in the order of ansatz.param_names, skipping hardcoded ones) returns the cost.

  • classic_cost_function: use the cost function of Houdayer & Hartmann (2004) (per-point, local linear master curve) instead of the integral cost.
  • use_all_sizes: include a curve's own size when building the master curve it is compared to (default: leave it out).
  • window_width: fraction of the scaled overlap window used by the integral cost.
  • eval_window = (lo, hi): use the fixed-window cost. Only data points with lo ≤ x ≤ hi in the raw (unscaled) x are scored, independently of the parameters. Points outside it still serve as interpolation knots. Where another size does not cover a point's scaled x, its curve is extrapolated linearly and a smooth penalty penalty * d^2 is added (d = distance outside, in units of that size's scaled range).
  • fix: NamedTuple of parameters held at fixed values, e.g. fix=(; a=1/ν). They are left out of the arguments of the cost function.

Only the columns used by ansatz are read. Rows with missing or non-finite values in them, or with a non-positive error, are skipped with a warning. System sizes must be positive integers, each size needs at least two usable rows, and no two rows may share the same size and x.

The Autoscaler reuses internal buffers between calls, so a single instance must not be evaluated from several threads at once.

References

  • J. Houdayer and A. K. Hartmann, Low-temperature behavior of two-dimensional Gaussian Ising spin glasses, Phys. Rev. B 70, 014418 (2004), doi:10.1103/PhysRevB.70.014418.

Autoscalers.cost_breakdown — Function
cost_breakdown(a::Autoscaler, args...)

Return (; cost, chi2, penalty) at the free parameters args (same convention as calling the Autoscaler). Requires eval_window. A non-negligible penalty means the fit relies on extrapolated curves; shrink eval_window.

Fitting and error estimates

Autoscalers.fit_collapse — Function
fit_collapse(
    a::Autoscaler, x0;
    method=NelderMead(...), options=Optim.Options(...), restarts=1,
)

Minimise the cost of a over its free parameters with Optim.jl, starting from x0. Returns a NamedTuple (; params, cost, converged, result), where result is the last Optim result.

By default this uses the Nelder–Mead simplex method (Nelder & Mead, 1965), with a small initial simplex around x0, and restarts it restarts times from the previous minimum, because a single run can stall in an elongated simplex. Any derivative-free Optim method and options can be passed instead.

References

  • J. A. Nelder and R. Mead, A simplex method for function minimization, Comput. J. 7, 308 (1965), doi:10.1093/comjnl/7.4.308.

Autoscalers.bootstrap — Function
bootstrap(
    a::Autoscaler, estimate;
    n=1000, rng=Random.default_rng(), parallel=true, progress=true,
    method=NelderMead(...), options=Optim.Options(...),
)

Parametric bootstrap of the free parameters around their fitted values estimate (Efron & Tibshirani, 1993; Davison & Hinkley, 1997).

The fitted collapse is taken as the true model: at estimate, the master curve of all sizes (the error-weighted mean of the sizes covering each point) is mapped back to the data by inverting the ansatz for the first column with errors. Each of the n replicates adds Gaussian noise of the measured errors to that model (and to the other columns with errors), and refits the parameters with fit_collapse, using method and options, starting from estimate.

Replicates run on all Julia threads if parallel (start Julia with --threads), and are reproducible for a given rng regardless of the number of threads. progress shows a progress bar.

The spread of the samples estimates the statistical error only. Systematic errors, for example from the choice of eval_window or corrections to scaling, are not included.

References

  • B. Efron and R. J. Tibshirani, An Introduction to the Bootstrap, Chapman & Hall (1993), doi:10.1201/9780429246593 (CRC reprint).
  • A. C. Davison and D. V. Hinkley, Bootstrap Methods and their Application, Cambridge University Press (1997), doi:10.1017/CBO9780511802843.

Autoscalers.BootstrapResult — Type
BootstrapResult

Result of bootstrap. Use confint, stderror and pvalue on it. Only the replicates whose fit converged are used.

  • estimate: the free parameters the bootstrap was run at.
  • samples: one row of refitted free parameters per replicate.
  • converged: whether each replicate's fit converged.

StatsAPI.confint — Method
confint(b::BootstrapResult; level=0.95)

Bias-corrected percentile (BC) confidence intervals (Efron, 1987) of every free parameter, as a NamedTuple of (lower, upper).

The bounds are the quantiles of the bootstrap samples at levels Φ(2z₀ ± z_{α/2}), with α = 1 - level, where z₀ = Φ⁻¹(P(θ* < θ̂)) measures how far the bootstrap distribution is off-centre from the estimate. For a centred distribution (z₀ = 0) this is the plain percentile interval (Efron & Tibshirani, 1993). The intervals follow the shape of the bootstrap distribution, so they can be asymmetric around the estimate, and need no extra fits. On synthetic collapses they are close to their nominal coverage (see test/scripts/bootstrap_coverage.jl). A large |z₀| moves the levels towards 0 or 1, so such quantiles need correspondingly many replicates (n ≳ 1000).

Other intervals can be computed from the samples in b.samples (rows of replicates whose fit converged are marked in b.converged).

References

  • B. Efron and R. J. Tibshirani, An Introduction to the Bootstrap, Chapman & Hall (1993), doi:10.1201/9780429246593 (CRC reprint).
  • A. C. Davison and D. V. Hinkley, Bootstrap Methods and their Application, Cambridge University Press (1997), doi:10.1017/CBO9780511802843.
  • B. Efron, Better bootstrap confidence intervals, J. Am. Stat. Assoc. 82, 171 (1987), doi:10.1080/01621459.1987.10478410.

StatsAPI.pvalue — Method
pvalue(b::BootstrapResult, name => value...; method=:bc, kwargs...)

Two-sided p-value of the hypothesis that the parameters name equal value.

  • method=:bc (default, no extra fits) tests one parameter and is the test dual to the BC interval of confint (Efron, 1987): p < 1 - level exactly when value lies outside the interval of that level, up to the resolution of the replicates. The fractions of samples below and above value, with the +1 correction of Davison & Hinkley (1997), are mapped through Φ(Φ⁻¹(P) ∓ 2z₀), and p is twice the smaller one. On the side towards which the BC interval is stretched, the smallest attainable p-value is 2Φ(Φ⁻¹(1/(n + 1)) + 2|z₀|): about 0.005 for n = 1000 and |z₀| = 0.15, but 0.06 for |z₀| = 0.6. To reject strongly off-centre cases, use more replicates or method=:null.
  • method=:null follows the first guideline of Hall & Wilson (1991) and resamples under the hypothesis. The parameters are refitted with name fixed at value; replicates are drawn from that constrained collapse, and each is fitted with and without the constraint. The p-value is the fraction of replicates whose cost increase from the constraint is at least the observed one (again with the +1 correction). It accepts several parameters at once and needs 2n fits. The keyword arguments n (default: the number of replicates of b), rng, parallel and progress are as for bootstrap.

References

  • B. Efron and R. J. Tibshirani, An Introduction to the Bootstrap, Chapman & Hall (1993), doi:10.1201/9780429246593 (CRC reprint).
  • A. C. Davison and D. V. Hinkley, Bootstrap Methods and their Application, Cambridge University Press (1997), doi:10.1017/CBO9780511802843.
  • B. Efron, Better bootstrap confidence intervals, J. Am. Stat. Assoc. 82, 171 (1987), doi:10.1080/01621459.1987.10478410.
  • P. Hall and S. R. Wilson, Two guidelines for bootstrap hypothesis testing, Biometrics 47, 757 (1991), doi:10.2307/2532163.
